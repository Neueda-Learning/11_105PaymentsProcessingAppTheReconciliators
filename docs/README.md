# PaymentsProcessingApp

A workflow-driven payment processing application developed as part of the Neueda Training Program.

## Project Overview

The system manages the complete payment lifecycle:

- Create Payment
- Validate Payment
- Send Payment
- Complete Payment
- Failure Handling

## Technology Stack

Backend
- Java
- Spring Boot
- PostgreSQL

Frontend
- React

Project Management
- Jira
- GitHub

Prototype
- Base44
